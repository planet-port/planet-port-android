# P4 UI 全量实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 iOS 端 SwiftUI 视图树为唯一基准，把验证脚手架替换为正式 Compose UI，功能与视觉对齐 planet-port-ios。

**Architecture:** 单 Activity + Compose 手写页面切换（不引 Navigation 库）；按页 ViewModel 共享 StoreRepo + TunnelController；状态从 TunnelStateBus StateFlow 读取、命令走 VM 方法。启动模型对齐 iOS——无独立启停按钮，网络开关驱动隧道生命周期。

**Tech Stack:** Jetpack Compose（BOM 2025.12.01，已有）+ lifecycle-viewmodel-compose（已锁未接，本阶段接入）+ material-icons-extended + appcompat 1.6（per-app language）+ CameraX + zxing-core（扫码，T7）。

## 既定决策（对齐裁决，实现时不再讨论）

1. **启动模型**：对齐 iOS——JoinNetworkSheet「加入」仅保存（lastActivated=false 不连接）；开网络开关 = 激活行星 + （隧道未跑则经 VPN 授权后 start）；关某行星最后一个启用网络 = `ZeroTierVpnService.stop()`；P2SelfCheck 与启停按钮退役。首次 VPN 授权走 MainActivity.requestVpnPermission 既有链。
2. **peers 数据源**：SDK 已有 `Node.peers(): Peer[]`（address/versionMajor×3/latency/role/paths）。NodeRuntime 包装查询，TunnelStateBus 加 `peers: StateFlow<List<PeerInfo>>`，隧道运行时 5s 周期刷新（对齐 iOS pollRuntime 节奏），PeerListView 打开时即拉 + 下拉刷新。
3. **详情页快照**：`VirtualNetworkConfig` 已含全部字段。NetConf 扩展 `type/bridge/broadcastEnabled/dhcp` 透传，TunnelStateBus 加 `networkConfigs: StateFlow<Map<String, NetConf>>`（TunnelManager 快照登记时同步推送——iOS 拉模式改推模式，同进程更自然）。
4. **状态文案上移**：`ztStatusText`（0..6 → 文案）从 P2SelfCheck 移入 ui 层公共模块；跨层只传原始 Int（iOS 契约）。`NetworkCardStatus` 五级判定完整移植（iOS 侦查 §2.5 优先级）。
5. **语言**：appcompat 1.6 per-app locale（`AppCompatDelegate.setApplicationLocales` + autoStoreLocales）+ values-zh-rTW / values-en；默认中文；215 key 从 iOS Localizable.xcstrings 移植（T7）。
6. **毛玻璃/视差**：minSdk 23——头区用半透明色降级（API 31+ 可选 RenderEffect 增强不做要求）；视差用 SensorManager 加速度计，无传感器静止。
7. **扫码**：CameraX + zxing-core（均 Apache-2.0）；CAMERA 运行时权限，被拒显示引导（对齐 iOS camera.on.rectangle 态）。
8. **背景图**：PickVisualMedia 相册选图 + URL 下载 + 清除三入口（对齐 iOS）；存 filesDir/background.img；首页蒙纱（浅 0.4/深 0.78）。
9. **多网络软上限**：AppPrefs 加 `maxNetworks: Int`（2..6 默认 2），超限弹 AlertDialog 可强制开启；开启第二个网络自动关闭全部 routeVia 并提示（iOS 侦查 §2.1 行为细节）。
10. **图标体系**：Material Icons 映射按 iOS 侦查 §6 表；行星图标目录 12 个语义等价图标 + djb2 哈希确定性分配（对齐 iOS PlanetIcon.swift）。

```kotlin
object ThemeManager {
    // iOS ThemeManager.swift:10-19 八预设国画色板
    val presets = listOf(
        0xFFD44037, 0xFFFFB61E, 0xFF789262, 0xFF57C3C2,
        0xFF4C8DAE, 0xFF003472, 0xFF4A4266, 0xFF9D2933,
    )
    /** 内存态运行值；持久化字段（AppPrefs.themeColor 等）由 Task 4 PrefsView 双写接线 */
    val accent = MutableStateFlow(0xFFD44037)
    val successDerived = MutableStateFlow(true)

    /** 深色模式提亮：s+0.2, l=min(0.72, l+0.14)（iOS :60-65）；HSL 转换手写小函数 */
    fun accentFor(dark: Boolean): Color = if (dark) hslAdjust(accent.value) else Color(accent.value)
    /** success 可选随主色 +120° 三角派生（iOS :68-75）；否则用资产双色 */
    fun successFor(dark: Boolean): Color = if (successDerived.value) hslRotate(accentFor(dark), 120f)
        else if (dark) Color(0xFF27B850) else Color(0xFF009830)
}
```
